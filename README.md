# Library Resourse and Loan Helper.
ITM 1131 Web Application Development | Group 5

**Live site:** https://achen-concy.github.io/library-helper/
**Repository:** https://github.com/achen-concy/library-helper

## Problem
Students and lecturers waste time finding library resources, checking whether they are available, reserving them, and tracking return dates.

##Intended users
Students, lecturers, and library staff.

##Features
- Catalogue of 8 sample IT and Information Systems resources
- Search by title or auther, with category and availability filters
- Reservation-request from with validation
- Loan page with expected return date, overdue status and fine estimate
- Responsive layout for mobile, tablet and desktop

##echnologies
HTML5, CSS3 (Flexbox and Grid), JavaScript. No frameworks, no datsbase.

## Limitations
- Sample data only; there is no login or database
- Reservations are not saved after the page is reloaded
- Fines rate and loan periods are sample values
